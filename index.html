Getting Started

Get started with Catploit and learn the basics.

01

Download the External

Download the latest version of Aetrx External from the Downloads page. Save it to a location you can easily access.

02

Disable Antivirus

Temporarily disable your antivirus software. This is required because the External interacts with Roblox's process memory, which may trigger false positives.

03

Open Roblox

Launch Roblox and join any experience. Make sure Roblox is fully loaded before proceeding.

04

Run the External

With Roblox open and running, launch the Aetrx External. The interface will appear and you can begin cheating.
